# 프론트엔드 데이터 폴더

프론트엔드 화면에서 쓰는 파일(배경 이미지, 로고, 효과음, 연출 자료)을 모아 두는 곳입니다. 서버 데이터가 아니라 화면용 정적 파일입니다.

## 구조

- `screens/`: 메인 화면 자료
  - `main-day.gif`: 메인 화면 배경 (576 × 1025, 움직이는 GIF). 1배로 표시합니다.
  - `title-logo.png`: 메인 화면 제목 로고 (PokéNav)
- `sounds/`: 효과음
  - `choose_sound.mp3`: 메뉴 선택과 방향키 이동에 쓰는 효과음
- `plasma/`: 플라스마단 연출 자료 (띠, 문양 PNG(`plasma-emblem.png`, 멈춘 그림)·GIF(`plasma-emblem.gif`, 반짝이는 그림), 게치스·N PNG, 번개 GIF). 게치스와 N 연출, 트레이너 정보 첫 화면의 플라스마단 카드가 같이 씁니다.
- `elite/`: 관장·사천왕 연출 자료 (노란 번개 GIF)
  - 번개 GIF 두 개는 원래 그림의 색과 모양을 그대로 두고 움직임만 늘린 것입니다 (32프레임, 꿈틀거림·번쩍 굵어짐).
- `ui/`: 목업 화면 자료 (로고, 하나지방 원본 지도 `map.png` 256×168 — 화면에는 쓰지 않고 지도 좌표(`map/hana-graph.json`)의 기준으로만 둠, 화면용 큰 지도 `map-large.png` 1228×806(사용자 제공 이미지. 노란 도로, 마을 원, 챔피언로드·섬의 작은 원, 초록 점을 깔끔하게 다시 그림. 위치는 원본과 같아서 좌표를 그대로 씀)). 현재 위치 빨간 원은 그림 없이 CSS로 그립니다 (마을 원의 청록 속과 같은 크기)
- `pokemon/`: 타입 상성표 (`type_chart.json`, 5세대). 서버에 상성 API가 없어 화면 계산용으로 둡니다. 포켓몬·장소·트레이너 정보는 서버 API에서 받습니다 (`src/api/`).
- `map/`: 맵 정보 데이터 (`hana-graph.json`: 마을·시티 원의 중심, 도로 선 가운데, 꿈터·동굴 같은 특정 장소(지도의 초록 점) 위치. 단위는 원본 지도 픽셀. `ids`는 장소 이름 → 서버 장소 API의 장소 ID)

## 인물 그림 (`public/trainer-images/`, 저장소 제외)

저작권 검토 전이라 저장소에는 올리지 않고 로컬 시연용으로만 둡니다. 파일 이름은 트레이너 ID입니다 (N은 `n` 하나를 공유).

| 파일 | 크기 | 쓰는 곳 |
|---|---|---|
| `{id}.png` | 80×80 전신 (발이 맨 아랫줄) | 상대 선택 패널, 트레이너 정보 첫 화면 카드, 맵 정보·포켓몬 상세의 인물 칸 |
| `{id}.gif` | 84×84 숨쉬기 (12프레임 × 0.18초, 그림은 2px 안쪽) | 상대 파티 화면의 큰 인물 칸, 첫 화면 카드에 마우스를 올렸을 때 |
| `bust/{id}.png` | 128×64 상반신 | 관장·사천왕·챔피언 등장 연출의 띠 |
| `marshal.gif` | 362×362 (받은 GIF) | 연무 상대 파티 화면 |
| `marshal-idle.gif` | 84×84 숨쉬기 | 연무 첫 화면 카드 (다른 인물 GIF와 같은 틀) |

- 숨쉬기 GIF는 전신 PNG의 윗몸을 1px 내려앉혔다 되돌려 만듭니다. 크기를 바꾸지 않고 줄을 반복하지 않아 픽셀이 늘어나 보이지 않습니다.
- `public/badge-images/`는 지금 쓰는 곳이 없습니다 (예전 배지 시험용).

## 관리 원칙

- 앞으로 프론트엔드에서 쓰는 이미지와 효과음은 이 `src/data/` 안에서 관리합니다.
- 인물 사진(`frontend/public/trainer-images/`)은 개발 중 임시로 저장소에서 제외(.gitignore)되어 있습니다. 공개 전에 사용 범위를 정한 뒤 이 폴더 구조에 맞춰 옮깁니다.

## 사용 규칙

- CSS에서는 `url("../data/screens/파일명")`처럼 상대 경로로 씁니다.
- 배경은 1배로 표시해서 픽셀이 흐려지지 않게 합니다.
- 효과음은 `src/sound.ts`에서 `SOUND_VOLUME`으로 볼륨을 조절합니다.
- 게임 원작에서 가져온 그림과 음원은 발표용으로만 쓰고, 공개 전에 사용 범위를 팀과 확인합니다.
- 파일을 추가하거나 바꾸면 이 README의 목록도 함께 고칩니다.
