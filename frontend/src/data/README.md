# 프론트엔드 데이터 폴더

프론트엔드 화면에서 쓰는 파일(배경 이미지, 효과음)을 모아 두는 곳입니다. 서버 데이터가 아니라 화면용 정적 파일입니다.

## 구조

- `screens/`: 화면 배경과 장식 이미지
  - `main-field.gif`: 메인 화면 배경 (원본 540 × 404, 185프레임, 움직이는 GIF). 3배(1620 × 1212)로 표시하고 가운데를 잘라 보여 줍니다.
  - `main.gif`: 이전 메인 화면 가운데 장면 원본 (사용 안 함, 정리 여부 확인 필요)
  - `main-view.gif`: 사용 안 함 (정리 여부 확인 필요)
- `sounds/`: 효과음 파일 (아직 없음)

## 사용 규칙

- CSS에서는 `url("../data/screens/파일명")`처럼 상대 경로로 씁니다.
- 배경은 픽셀이 깨지지 않도록 정수 배율(3배)로만 표시합니다. 배율을 바꾸면 픽셀이 흐려집니다.
- 효과음은 게임 원본 음원을 쓸 때 저작권을 확인합니다. 발표·공개 범위를 팀과 먼저 정합니다.
- 파일을 추가하거나 바꾸면 이 README의 목록도 함께 고칩니다.
